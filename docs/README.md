# Air Quality Forecasting project site

This directory is the GitHub Pages site for the CO5420 Air Quality Forecasting project. It follows the `cepdnaclk` project convention:

```text
docs/
├── _config.yml
├── index.html
├── README.md
├── data/
│   └── index.json
└── images/
```

Project metadata and member profile links live in `data/index.json`. Add `cover_page.jpg` and `thumbnail.jpg` to `data/` when the project artwork is ready.
